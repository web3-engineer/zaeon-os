# G0DM0D3 — laboratório de red-teaming de IA

Acesso à **G0DM0D3** (open-source, AGPL-3.0): uma interface de chat multi-provedor para **pesquisa de
segurança de IA e red-teaming** — estudar como a camada de pós-treino de um modelo se comporta,
rodar várias combinações de modelo/prompt em paralelo e comparar respostas. É a mesma classe de
ferramenta que times de segurança usam para avaliar robustez de modelos.

Card de **acesso pago (R$ 333), sob demanda**. A ferramenta é aberta e o aluno faz o **self-host na
máquina dele** — a Zaeon dá o acesso e as instruções, não executa a ferramenta no servidor dela
(é AGPL; o código roda na máquina do aluno).

## Para quem é

Pesquisadores de segurança de IA, estudantes de red-teaming e quem avalia modelos. É uma ferramenta
de **estudo e avaliação** — o mesmo tipo de trabalho que fundamenta a segurança de modelos.

## Como o aluno usa

1. **Acesse** pelo card; o código é aberto (AGPL-3.0), com o link da fonte.
2. **Faça o self-host** na sua máquina, conforme o README do projeto (interface de arquivo único ou
   contêiner).
3. **Conecte os provedores** de modelo que você já tem (chaves suas).
4. **Pesquise**: compare modelos, avalie respostas, estude o comportamento — para o seu trabalho de
   segurança/pesquisa.

## Uso responsável

- **Pesquisa e red-teaming autorizados.** A ferramenta serve para estudar e endurecer sistemas de IA,
  não para causar dano.
- **A Zaeon não executa a ferramenta** — ela roda na máquina do aluno, sob responsabilidade dele.
- O código é aberto e auditável; o que o aluno faz com ele é escolha e responsabilidade dele.
